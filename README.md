# Python Analytics Projects

This repository contains independent data-analysis and Python projects. The portfolio highlights two projects here:

## Featured projects

- **[NYC Payroll exploratory analysis](NYC-Payroll-Data-Project/README.md)** — a Jupyter analysis of city payroll, agency-level staffing and compensation, overtime, and fiscal-year trends.
- **[Recruitment intelligence pipeline](Jobs%20Project/README.md)** — a multi-source Python pipeline that collects, standardizes, deduplicates, and exports job postings.

The NYC payroll notebook expects its source CSV beside the notebook; that dataset is not committed with the project. See the project README for the source and workflow.

Other folders contain standalone course and visualization exercises. Each project’s scripts, notebooks, and supporting files are kept in its own directory.
